# Demo Compras

Prototipo interactivo de un dashboard de reportes de compras multicanal.

## Características

- Inicio de sesión simulado.
- Reportes consolidados con filtros por período.
- Indicadores KPI, búsqueda y paginación.
- Exportación a CSV y formato compatible con Excel.
- Historial de sincronizaciones.
- Configuración y prueba de fuentes de datos.
- Diseño responsive para escritorio y móvil.

## Uso

Abre `index.html` en un navegador con conexión a internet. Tailwind CSS, Font Awesome y la tipografía se cargan mediante CDN.

> Este proyecto utiliza datos simulados y está diseñado únicamente como demostración visual y funcional.
